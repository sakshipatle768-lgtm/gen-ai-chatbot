# Gen AI Chatbot

A simple Generative AI chatbot built using Python, Streamlit, LangChain, and Google Gemini.

## Features

- Ask questions in natural language
- Generate AI-powered answers
- Simple and user-friendly interface
- Uses LangChain PromptTemplate

## Technologies Used

- Python
- Streamlit
- LangChain
- Google Gemini

## How to Run

1. Install the required packages:
   `pip install -r requirements.txt`

2. Configure your Google Gemini API key.

3. Run the application:
   `streamlit run prompt.py`
